# Barraca do Baiano

esse projeto foi feito para uma lanchonete local, a **Barraca do Baiano**, e também faz parte dos meus estudos no curso de **Tecnologia em Sistemas para Internet (TSI) no IFRN**.

a ideia do site é ser bem simples: mostrar o cardápio, deixar a pessoa montar o pedido e no final mandar tudo pronto para o WhatsApp.

## como funciona

o cliente pode escolher os produtos pelo site, alterar quantidade, adicionar ou remover coisas do pedido e depois finalizar pelo WhatsApp.

na parte do pedido também dá para escolher a forma de pagamento:

- pix
- cartão
- dinheiro

se for dinheiro, também dá para informar se precisa de troco e para quanto.

quando a pessoa finaliza, o site monta uma mensagem com as informações do pedido e abre o WhatsApp.

## tecnologias

o projeto foi feito usando:

- HTML
- CSS
- JavaScript

não tem banco de dados, backend, login ou painel administrativo.

a ideia foi justamente deixar o projeto mais simples e fazer o pedido ser resolvido direto pelo WhatsApp.

## responsividade

também tentei deixar o site funcionando bem tanto no computador quanto no celular, já que provavelmente a maioria das pessoas vai acessar o cardápio pelo telefone.
